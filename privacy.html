Privacy Policy

CSK Photo Album AI Assistant

This application is a proof of concept developed for technical evaluation and demonstration purposes.

Information Processing

User questions are processed through Microsoft Foundry using an AI language model.

The assistant retrieves publicly available photo album information from the Chennai Super Kings REST API through a Model Context Protocol (MCP) server.

Data Handling

The application is intended for public CSK album information only. Users should not submit personal, confidential, or sensitive information.

Microsoft Azure and other infrastructure providers may process technical and diagnostic information according to their applicable service policies.

AI Responses

AI-generated responses may contain inaccuracies. Users should verify important information against official sources.

Contact

For questions about this demonstration, contact the repository maintainers.
